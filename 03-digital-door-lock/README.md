# Digital Door Lock

An Arduino-based digital door lock system built using Tinkercad.

## Components

- Arduino Uno R3
- 4x4 Keypad
- Servo Motor
- 16x2 LCD
- Breadboard
- Jumper Wires

## Features

- Password-based access
- Servo motor lock/unlock
- LCD status messages
- Wrong password detection
